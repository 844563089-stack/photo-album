📷 阿包旅行图册 · 上传照片教程

方式 A：GitHub 网页直接拖文件 —— 零命令行、零工具，10 分钟上手

GitHub 官网 注册账号 新建仓库 官方：上传文件 官方：新建文件 jsDelivr CDN
共 6 步 · 约 10 分钟
1 注册 GitHub 账号 只需一次 · 5 分钟
  1. 打开官网：github.com/signup
  2. 输入邮箱 → 设置密码 → 起一个用户名（例如 abao-travel）
  3. 完成邮箱验证码验证
⚠️ 国内访问 GitHub 偶尔慢或打不开，属正常现象。可稍等重试，或借助网络加速工具。
2 创建一个公开仓库（放照片的地方）
  1. 打开 github.com/new
  2. Repository name 填：photo-album
  3. 可见性选 Public（公开） —— 必须公开，网站才能免费读取
  4. 页面底部有 3 个可选选项（全部可不勾）：
    • Add README 添加 README → 可以勾（GitHub 帮你建个占位 README，等下传代码时被覆盖）
    • Add .gitignore 添加 .gitignore → 不勾（项目已有自带 .gitignore）
    • Add license 添加许可证 → 推荐勾 MIT（最宽松：别人署名就能用）
  5. 点绿色 Create repository 创建仓库
💡 仓库名可以随便起，但要和网站 config.js 里的 repo 完全一致。
3 把网站文件放进仓库（只做一次）

网站的代码文件（index.html / style.css / app.js / config.js 等）需要先放进去一次，之后就不用管了。

  1. 进入你的仓库主页（github.com/你的用户名/photo-album）
  2. 点绿色按钮 Add file → Upload files
  3. 把本地 photo-album/ 文件夹里的这些文件拖进去：
    index.html  ·  style.css  ·  app.js  ·  config.js  ·  README.md
    photos/（整个文件夹一起拖，若提示空文件夹，则先执行第 4 步再回来）
  4. 点底部绿色 Commit changes 提交
4 创建日期文件夹（以后每趟旅行一个） 关键技巧

GitHub 网页版不能创建空文件夹，必须带一个文件一起创建。所以我们的"文件夹" = 一个带 meta.json 的目录，顺便把标题/地点写进去，一举两得。

  1. 仓库页面 → Add file → Create new file
  2. 在文件名输入框里完整输入（带斜杠会自动建文件夹）：
    photos/2026-08-31/meta.json
  3. 在下方编辑区粘贴（改你自己的信息）： 
    {
  "title": "东湖樱花",
  "location": "武汉",
  "province": "湖北",
  "description": "三月的东湖，粉白一片。",
  "tags": ["湖光", "城市漫步"]
}
  4. 点 Commit changes —— 此时文件夹 photos/2026-08-31/ 就建好了
💡 不想写任何信息？meta.json 里填 {} 也行，网站会用日期当标题正常展示。
✅ 以后每个新行程，重复第 4 步，日期换成旅行当天的日期即可。
5 拖入照片 核心操作
  1. 在仓库里点进 photos/2026-08-31/（刚建好的目录）
  2. 点 Add file → Upload files
  3. 把当天的照片全选直接拖进网页虚线框（一次最多 100 张，可分批）
  4. 点 Commit changes 完成
photos/
  ├── 2026-08-31/
  │   ├── meta.json
  │   ├── 01.jpg  ← 建议数字前缀命名，决定排序
  │   ├── 02.jpg
  │   └── 03.jpg
  ├── 2026-05-16/
  └── 2025-11-08/
💡 想给照片单独起名/标景点？在 meta.json 里加 "captions": {"01.jpg": "东湖绿道入口"} 即可。
⚠️ 支持格式 .jpg/.jpeg/.png/.webp/.gif；单张建议 < 5MB（GitHub 单文件上限 25MB）。
6 等 CDN 同步，刷新网站
  1. 首次提交后，先"预热"一次 CDN 缓存（可选但推荐）：浏览器打开
    https://cdn.jsdelivr.net/gh/你的用户名/photo-album
  2. 等 5~10 分钟，jsDelivr 完成同步
  3. 刷新你的图册网站 → 新相册自动出现（最新日期排在最前）
✅ 之后每次上传新照片，都只需：建日期文件夹（第 4 步）→ 拖照片（第 5 步）→ 等 5 分钟。

常见问题

Q0. 我建了一个"相册"目录但传了照片没显示

原因：网站读取的是配置里的 photos 目录（见 config.js 的 photosPath: 'photos'）；如果你建了其它名字的目录（如"相册"），网站不会读它。解决：① 进那个目录 → 右上 ··· → Delete directory → Commit 删掉 ② 回到仓库根目录，按本教程第 4 步的方法建 photos/2026-08-31/ 日期文件夹。日常所有照片/相册信息只在 photos/ 下。

Q0.5 仓库名能不能用中文或带空格？

不能。jsDelivr CDN（我们用的免费图床）拒绝含中文、空格或非 ASCII 字符的仓库名（实测返回 400）。建库时务必用纯英文+短横线，例如 photo-album、my-trip。建好之后也可以改名：仓库首页 → 右上 Settings → 滚到底 Rename → 输入 photo-album → Rename。

Q1. GitHub 网站打不开 / 很慢

国内访问 GitHub 偶发不稳定，稍等重试或使用网络加速工具。也可以改用「腾讯云 Serverless / Cloudflare Pages」部署，但照片仍建议存 GitHub（免费 + jsDelivr 国内 CDN 加速）。

Q2. 拖照片显示"太大了"

GitHub 单文件上限 25MB。手机原图一般没问题；超大原图建议先用手机相册压缩到 5MB 以内再传。

Q3. 为什么上传了但网站没显示

① jsDelivr 缓存还没同步（等 5-10 分钟）② 文件夹名不是 YYYY-MM-DD 日期格式 ③ 照片格式不在白名单。逐项排查即可。

Q4. 我要改标题 / 补标签怎么办

仓库里点进 photos/日期/meta.json → 点铅笔图标 ✏️ 编辑 → Commit changes → 等 5 分钟。或者用本地工具 node _tools/photo-tool.mjs edit 2026-08-31。

Q5. 往老相册加照片

进到对应日期文件夹 → Upload files 拖新照片 → Commit，它会自动出现在那个相册里（按文件名排序）。

Q6. 一次传很多照片很麻烦？

① 网页一次最多 100 张，分批传；② 或等配置好本地 git 后，用 node _tools/photo-tool.mjs new + push 一条龙。
